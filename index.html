재개발 철거 과정에서 엄마와 형제들과 헤어진 턱시도 고양이가 가족의 흔적을 따라 하천, 시장, 도심, 놀이터, 공업지대, 아파트, 폭우 속 고가도로, 하수도를 거쳐 주택가에서 가족과 재회하는 여정을 다룬다.

모든 적을 단순한 악당으로 만들지 않는다. 동물은 생존·영역·두려움·배고픔 때문에 충돌하며, 인간과 도시 환경은 작은 고양이의 시점에서 거대한 위험으로 표현한다. 가능한 한 적은 죽지 않고 물러나거나 도망간다.

3. 10개 스테이지 스토리 시나리오

STAGE 1. 재개발 지역 — 「사라진 집」

일반 적/위협: 까마귀, 들개/경비견, 철거 인부, 공사 차량, 낙하물

보스: 철거반 작업반장

주요 패턴: 망치 던지기 / 뛰어서 추격 / 소리 지르기

시나리오: 철거 혼란으로 가족과 헤어진다. 보스전 뒤 엄마와 형제들의 발자국이 하천 방향으로 이어진다.

STAGE 2. 하천 / 강가 — 「너도 혼자구나」

일반 적/위협: 하천 쥐, 까마귀, 물고기, 왜가리, 떠돌이 개

보스: 버려진 들강아지

주요 패턴: 돌진 / 물기 / 짖기

시나리오: 패배 후 오래된 목줄 자국을 통해 버려진 존재임을 알게 된다. 가족이 시장 방향으로 갔다는 단서를 얻는다.

STAGE 3. 시장 골목 — 「먹을 것이 있는 곳」

일반 적/위협: 시장 쥐, 비둘기/까마귀, 영역 고양이, 배달 오토바이, 손수레

보스: 시장 대장 고양이

주요 패턴: 앞발 연타 / 덮치기 / 하악질

시나리오: 대장이 냄새를 맡고 엄마와 새끼들이 먹이를 구한 뒤 도심으로 이동했다고 알려준다. 가족 생존의 첫 확실한 단서.

STAGE 4. 밤의 도심 — 「불빛 속의 그림자」

일반 적/위협: 도시 쥐, 비둘기, 길고양이, 자전거, 오토바이, 자동차, 사람 발

보스: 술 취한 아저씨

주요 패턴: 비틀거림 / 발차기 / 빈 캔 던지기 / 추격 / 소리

시나리오: 직접 쓰러뜨리기보다 회피 중심. 취객은 지치거나 스스로 넘어진다. 가족이 오래된 놀이터 쪽으로 이동했다는 단서.

STAGE 5. 오래된 놀이터 — 「잊힌 기억」

일반 적/위협: 장난감 병정, 고양이 인형, 장난감 자동차, 태엽 로봇, 고장 난 드론

보스: 오래된 대형 로봇

주요 패턴: 로켓 펀치 / 레이저 / 미사일 / SYSTEM ERROR

시나리오: 폭발해 죽지 않고 전원이 꺼진다. 마지막 순간 자신을 사랑했던 어린 주인의 손과 웃음, 포옹을 기억하며 '고마워…'라는 정서를 남긴다.

STAGE 6. 공업·창고지대 — 「지켜야 하는 것」

일반 적/위협: 경비견, 감시 드론, 지게차, 운반 로봇, 작업 인부, 순찰 로봇, 낙하 화물

보스: 경비견 대장

주요 패턴: 돌진 / 물기 / 앞발 내려찍기 / 짖기

시나리오: 엄마의 털과 약간의 피, 새끼들의 발자국을 발견한다. 엄마가 다쳤지만 새끼들을 지키며 계속 이동했음을 알게 된다.

STAGE 7. 아파트 단지 — 「상처받은 아이」

일반 적/위협: 자전거 아이, 롤러블레이드 아이, 스케이트보드 아이, 장난치는 아이, 단지 길고양이

보스: 상처 많은 고등학생

주요 패턴: 발차기 / 돌멩이 / 추격 / 소리

시나리오: 스트레스를 약한 존재에게 푸는 행동을 정당화하지 않는다. 마지막 공격을 멈추고 어릴 적 길고양이에게 먹이를 주던 기억을 떠올린다. 비가 시작된다.

STAGE 8. 폭우 속 고가도로 — 「그래도 가야 해」

일반 적/위협: 들개, 까마귀, 차량 물보라, 도로 장애물, 쓰레기통, 낙하물, 침수 웅덩이

보스: 들개 무리 대장

주요 패턴: 돌진 / 포위 / 연속 물기 / 울부짖기

시나리오: 폭우로 냄새와 발자국을 잃고 좌절한다. 다리 아래에서 가족이 비를 피했던 흔적과 하수구로 향하는 희미한 발자국을 발견하고 다시 일어난다.

STAGE 9. 지하 하수도 — 「빛을 향해서」

일반 적/위협: 하수도 쥐, 거미, 바퀴벌레, 지네, 독거미, 변이 쥐, 환경 위험

보스: 독두꺼비

주요 패턴: 긴 혀 / 독액 / 점프 내려찍기 / 독안개

시나리오: 독두꺼비는 패배 후 물속으로 도망간다. 빛이 들어오는 사다리와 맨홀을 통해 주택가로 나온다.

STAGE 10. 주택가 — 「집으로」

일반 적/위협: 경계냥, 골목냥, 지붕냥, 영역 고양이, 아기 길고양이, 마을 고양이 무리

보스: 마을 길고양이 대장

주요 패턴: 할퀴기 / 덮치기 / 하악질 / 연속 앞발

시나리오: 대장이 냄새를 맡고 공격을 중단한다. 가족이 근처 집에서 구조되었다고 알려준다. 마지막 입력 '엄마' 후 키보드와 전투 HUD가 사라지고 주인공은 입력 없이 스스로 가족에게 달려간다.

4. 핵심 게임 루프와 2D 횡스크롤 액션

위험 발생 → 적 공격 예고(Telegraph) → 행동 단어 표시 → 한글 IME 입력 → 정답 판정 → 즉시 Player Animation → 적/환경 Reaction → Combo → 묵찌빠 충전 → 다음 상황
대표 행동 단어: 공격 / 피해 / 점프 / 숙여 / 막아 / 달려 / 넘어. 정확한 단어가 완성되는 순간 행동하며, 가능하면 별도 Enter/입력 버튼을 요구하지 않는다.

플레이어 최소 애니메이션 상태

IDLE / WALK / RUN / ATTACK / JUMP / FALL / LAND / DUCK / DODGE / GUARD / HIT / KNOCKBACK / SPECIAL

공격

정답 → 몸 낮추기 → 짧은 돌진 → 앞발 공격 → Hit Flash + Hit Stop + Pixel Impact → 적 Knockback → 적 HP 감소 → 묵 게이지 충전

회피

  • 점프: 웅크림 → 도약 → 공격 통과 → 착지
  • 숙이기: 몸 낮춤 → 공격 통과 → 복귀
  • 피해: 빠른 백스텝 → 먼지 픽셀 → 착지
  • 달려: Run 속도와 카메라 스크롤 증가 → 위험구역 탈출
  • 회피 성공은 찌 게이지 충전 조건으로 사용

방어

‘막아’ 성공 → GUARD → Impact → 약간 밀림 → 피해 감소 / Perfect Guard는 피해 0 / 실패는 정상 피해

5. 적 등장·공격·피격 애니메이션 기준

SPAWN → ENTER → APPROACH → NOTICE → WARNING → ATTACK_PREPARE → WORD DISPLAY → INPUT WINDOW → ATTACK → PLAYER RESPONSE → HIT/MISS → RECOVER → NEXT ATTACK/RETREAT
  • 지상 동물: 화면 오른쪽 밖 → 일부 실루엣 → 자연스럽게 진입 → 주인공 발견 → 경계 자세.
  • 비행 적: 배경의 작은 실루엣 → 접근/확대 → 공격 위치 이동 → 급강하.
  • 인간: 일상 행동 → 고양이 발견 → 시선/몸 방향 전환 → 경고 → 추격/행동.
  • 기계: 대기 → 센서 점등 → 플레이어 감지 → 작동 → 공격 준비.
  • 강한 공격일수록 Telegraph를 길고 명확하게 제공한다. 피할 수 없는 갑작스러운 공격은 최소화한다.

6. 묵·찌·빠 지원 캐릭터 — 확정 애니메이션 사양

세 지원 캐릭터는 각각 3칸 게이지를 사용한다. MAX 상태에서 해당 캐릭터 버튼을 터치하면 전투 흐름 속에 자연스럽게 난입한다.

👊 묵 — 계란이 : 위→아래 앞발 할퀴기 공격

묵 MAX 터치 → 주인공 뒤(왼쪽 화면 밖)에서 계란이 달려옴 → 주인공을 추월 → 주인공 앞에서 짧게 정지 → ✨ 반짝!! 발동 → 적을 향해 재가속 → 적 앞에서 점프 → 공중에서 앞발을 들어 올림 → 위에서 아래로 강하게 할퀴기 → 💥 타격 → 적 HP 감소 + Knockback → 착지 → 오른쪽 화면 밖으로 퇴장
  • 핵심 모션: RUN_IN → STOP → SPARK → RUN → JUMP → PAW_UP → DOWN_SLASH → IMPACT → LAND → RUN_OUT.
  • 반짝 효과는 약 0.2~0.3초의 강한 단발성 픽셀 광원 효과.
  • 옆으로 긁는 동작보다 위→아래로 내려찍듯 할퀴는 동작을 기준으로 한다.
  • 역할: 직접 공격형. 단일 적/보스에게 명확한 타격감을 제공한다.

✌ 찌 — 삼순이 : HP(에너지) 회복

찌 MAX 터치 → 왼쪽에서 삼순이 등장 → 주인공에게 접근 → 주인공 옆에서 정지/몸을 붙임 → ✨ 작은 빛이 반짝반짝 지속 → 회복 입자가 주인공 주변으로 이동/흡수 → HP(에너지) 게이지가 단계적으로 차오름 → 회복 완료 시 마지막 반짝임 → 삼순이 퇴장
  • 핵심 모션: RUN_IN → APPROACH → RUB/CONTACT → HEAL_SPARKLE → ENERGY_TRANSFER → COMPLETE_SPARK → EXIT.
  • 계란이의 단발성 '반짝!!'과 달리 여러 개의 작은 반짝임이 지속되는 부드러운 회복 효과.
  • 현재 기획상 삼순이는 주인공 HP(에너지)를 채우는 회복 지원 역할로 취급한다. 실제 구현 전 HP와 별도 ENERGY를 분리할지 프로젝트 구조에 맞춰 최종 확정한다.

🖐 빠 — 남순이 : 직선 고속 몸통박치기

빠 MAX 터치 → 주인공 뒤(왼쪽 화면 밖)에서 남순이 달려옴 → 주인공을 추월 → 주인공 앞에서 짧게 정지 → ✨ 반짝!! 발동 → 몸을 낮춰 돌진 자세 → 적을 향해 직선 고속 돌진 → 뒤쪽에 속도 잔상/먼지 → 적과 충돌 → 💥 강한 몸통박치기 Impact + 짧은 Hit Stop → 적 HP 감소 + 강한 Knockback → 남순이 짧은 충돌 반동 → 자세 회복 → 오른쪽으로 퇴장
  • 핵심 모션: RUN_IN → STOP → SPARK → CHARGE_READY → BODY_CHARGE → IMPACT → REBOUND → RECOVER → RUN_OUT.
  • 기존 구르기 공격은 사용하지 않는다. 정식 설정은 직선 몸통박치기다.
  • 계란이는 수직적인 위→아래 타격, 남순이는 수평적인 고속 충돌로 실루엣과 타격감을 구분한다.

13-1. 일시정지 메뉴에 ‘타이틀로 돌아가기’ 기능 추가

현재는 게임 도중 일시정지는 가능하지만 현재 플레이를 종료하고 타이틀 화면으로 돌아가는 기능이 없다. Pause Menu를 단순 Resume 기능만 가진 화면이 아니라 플레이 세션을 관리하는 메뉴로 확장한다.

게임 중 PAUSE 버튼 → 게임 로직/타이머/적 AI/입력 판정 일시정지 → PAUSE MENU 표시 [계속하기] [처음부터 다시하기] [타이틀로 돌아가기] 타이틀로 돌아가기 선택 → 확인 팝업 “현재 진행 상황을 종료하고 타이틀 화면으로 돌아갈까요?” [취소] [타이틀로] 확정 → 현재 Stage/Wave/Boss/Enemy/Combo/입력 상태 정리 → 게임 세션 종료 → IME/키보드 정리 → 타이틀 화면으로 전환
  • ‘계속하기’는 현재 상태를 그대로 복원한다.
  • ‘처음부터 다시하기’는 현재 스테이지를 초기 상태로 재시작한다.
  • ‘타이틀로 돌아가기’는 실수 방지를 위해 확인 절차를 둔다.
  • 타이틀 복귀 시 Enemy coroutine/timer/animation/game loop가 뒤에서 계속 실행되지 않도록 정리한다.
  • Android Back 동작도 게임 중에는 곧바로 Activity 종료보다 Pause Menu를 먼저 여는 방향을 우선 검토한다.

13-2. 적 캐릭터 움직임을 ‘루즈한 이동’에서 ‘행동이 읽히는 액션’으로 개선

Alpha 0.1.2에서는 적 캐릭터가 화면 안에서 이동하거나 대기하는 구간이 길고, 접근·경계·공격 준비 사이의 시각적 변화가 약해 전투가 느슨하게 느껴진다. 단순히 이동 속도만 올리지 말고 속도 변화 + 행동 상태 + 애니메이션 + Telegraph를 함께 개선한다.

ENTER → APPROACH → NOTICE → WARNING → ATTACK_PREPARE → ATTACK → RECOVER → REPOSITION / NEXT ATTACK
  • ENTER: 화면 밖에서 자연스럽게 진입. 일정한 미끄러짐 이동 금지.
  • APPROACH: 짧은 가속과 감속을 사용하여 살아 있는 생물처럼 접근.
  • NOTICE: 주인공을 발견하면 머리/몸 방향 전환, 1회 움찔, 경계 포즈 등 명확한 반응.
  • WARNING: 공격 직전 색상/눈/몸 자세/작은 경고 이펙트로 플레이어가 다음 공격을 읽을 수 있게 한다.
  • ATTACK_PREPARE: 공격 종류마다 고유한 예비 동작을 둔다.
  • ATTACK: 짧고 빠른 가속 구간을 사용하여 공격 순간의 속도감을 만든다.
  • RECOVER: 공격 후 바로 Idle로 돌아가지 말고 착지/헛발질/몸 추스르기 등의 후속 동작을 둔다.
  • REPOSITION: 같은 자리에서 공격만 반복하지 말고 짧게 물러나거나 위치를 바꾼 후 다음 공격을 준비한다.

13-3. 일반 적 애니메이션 최소 사양

IDLE_LOOP MOVE_LOOP NOTICE WARNING ATTACK_PREPARE ATTACK HIT KNOCKBACK RECOVER RETREAT

각 상태가 단순 좌표 이동만으로 표현되지 않도록 픽셀 애니메이션 또는 최소한 Scale/Offset/Flash/Dust 등의 보조 효과를 사용한다.

  • IDLE: 호흡, 꼬리, 귀, 몸의 미세 움직임.
  • MOVE: 실제 발걸음과 속도가 맞는 Walk/Run cycle.
  • NOTICE: 짧은 정지 + 시선/몸 방향 변화.
  • WARNING: 0.2~0.6초 정도의 공격 예고 동작.
  • ATTACK: 시작→가속→충돌/공격→후속 동작이 보이게 한다.
  • HIT: Hit Flash + 1~2px 반동 + 짧은 Hit Stop.
  • KNOCKBACK: 공격 방향과 반대로 밀리며 발/몸 자세 변화.
  • RETREAT: HP 0 또는 전투 종료 시 즉시 삭제하지 않고 화면 밖으로 도망/후퇴.

13-4. 적 종류별 ‘움직임 성격’을 다르게 한다

13-5. 전투 타격 애니메이션과 화면 효과 보강

현재 전투는 입력 성공 여부가 UI와 수치에 집중되어 보일 수 있으므로, 모든 성공 입력을 반드시 화면의 물리적 액션으로 연결한다.

정답 입력 → Player / Support Attack Animation → Enemy HIT Animation → Hit Flash → 40~80ms 수준의 짧은 Hit Stop → Pixel Impact → Knockback → 아주 약한 Camera Shake → HP 감소 표시 → Combo / Gauge 반응
  • 타격 순간만 아주 짧게 화면을 멈춰 충돌감을 만든다.
  • 피격 캐릭터를 1~2프레임 밝게 Flash 처리한다.
  • 공격 위치에 Slash/Impact/Dust 픽셀 효과를 추가한다.
  • 강공격이나 묵찌빠는 일반 공격보다 큰 Impact를 사용하되 화면 흔들림은 과하지 않게 한다.
  • 실패/MISS에도 별도의 시각 반응을 두어 입력 결과가 즉시 보이게 한다.

13-6. 적 이동 템포 및 전투 리듬 개선

루즈함을 해결하기 위해 모든 캐릭터의 MoveSpeed만 일괄 증가시키지 않는다. 구간별 속도와 대기시간을 조정한다.

  • 일반 접근 시간은 짧게.
  • 공격 전 Telegraph는 읽을 수 있을 만큼 명확하게.
  • 입력 성공 후 다음 상황까지 불필요한 공백을 줄인다.
  • 연속 전투에서도 입력 단어를 읽을 최소 시간은 보장한다.
  • Boss는 이동 속도보다 패턴 전환과 공격 리듬으로 압박감을 만든다.
  • Enemy Animation 속도와 실제 이동 속도가 어긋나 미끄러져 보이지 않게 한다.

13-7. Stage 1 작업반장 보스 애니메이션 보강

14-1. 게임 장르 및 조작 체계 변경

Alpha 0.1.2의 한글 타자 조작은 스마트폰 세로 화면에서 Android 키보드가 화면의 절반가량을 가려 게임 몰입도를 크게 떨어뜨렸다. Alpha 0.2.0부터는 가상 조이스틱 + 액션 버튼을 공식 조작 방식으로 사용한다.

왼쪽 하단: 가상 조이스틱 → 좌/우 이동 → 위 방향 입력으로 점프 → 별도 점프 버튼 없음 오른쪽 하단: [공격] [회피] [방어]
  • Android 키보드와 타자 입력 UI는 실제 게임 플레이에서 제거한다.
  • 별도 점프 버튼을 만들지 않는다. 점프는 조이스틱 위 방향으로 수행한다.
  • SP 게이지는 사용하지 않는다.
  • 물약/회복 아이템 버튼은 사용하지 않는다.
  • 주인공의 기본 상태 자원은 HP만 사용한다.
  • 기존 타자/IME 코드는 즉시 삭제하지 않고 우선 비활성화 또는 분리한 뒤 새 조작이 안정화되면 정리한다.

14-2. Portrait 세로형 전투 UI

게임 화면은 Portrait 세로형을 유지한다. 화면의 핵심은 최대한 넓은 전투 영역과 손가락이 자연스럽게 닿는 조작 영역이다.

  • 상단: Player HP / Stage / Boss HP(보스전) / 진행 정보 / 메뉴 버튼.
  • 중앙: 실제 횡스크롤 게임 플레이 영역.
  • 왼쪽 하단: 가상 아날로그 조이스틱.
  • 오른쪽 하단: 공격 / 회피 / 방어.
  • 하단 또는 조작부 위: 계란이(묵) / 삼순이(찌) / 남순이(빠) 3칸 특수 게이지.
  • SP, 물약, 점프 버튼, 타자창, TARGET WORD, CURRENT INPUT은 표시하지 않는다.

14-3. 게임 중 메뉴 통합

게임 화면에서 옵션/설정 성격의 버튼을 여러 개 두지 않는다. 우측 상단에 메뉴 버튼 하나만 둔다.

[계속하기] [스토리] [설정] [스테이지 다시 시작] [타이틀로 돌아가기]

‘스토리’는 별도 인게임 버튼이 아니라 메뉴 안에 넣는다. ‘타이틀로 돌아가기’는 확인 팝업 후 현재 전투 세션, 적 AI, Wave, Boss, Combo, Timer, Animation, Coroutine/Game Loop를 안전하게 종료하고 타이틀 화면으로 전환한다.

14-5. 특수 캐릭터 외형 레퍼런스

  • 계란이: 주황+흰색 바이컬러 치즈태비. 얼굴 중앙·입 주변·가슴·배·다리는 흰색, 머리와 등·꼬리는 주황 태비 무늬.
  • 삼순이: 검정·주황·갈색이 섞인 카오스/토터셸 계열, 흰 가슴·배·발, 얼굴 좌우의 비대칭 무늬가 특징.

14-6. Stage 1 첫 스토리 — 세 마리와의 만남

재개발 철거가 한창인 오래된 동네. 굴착기와 철거 소리, 먼지와 무너진 집 사이에서 주인공 턱시도 고양이는 엄마와 형제들을 잃고 혼자 남는다. 아무리 울어도 가족의 대답은 들리지 않고, 주인공은 무너진 담벼락 옆에 웅크려 외롭고 무서워한다.

그 모습을 철거 현장 근처를 지나가던 계란이, 삼순이, 남순이가 발견한다. 남순이가 먼저 주인공에게 가려 하고 계란이는 위험한 철거 현장을 살핀다. 삼순이는 겁에 질린 주인공에게 천천히 다가가 경계를 풀게 한다.

남순이: “형… 저기 고양이 혼자 있어.” 삼순이: “많이 무서운가 봐.” 계란이: “여긴 위험해. 우선 저 녀석부터 데리고 나가자.” 삼순이: “괜찮아. 우린 널 해치지 않아.” 주인공: “엄마랑… 형제들이 없어졌어.” 계란이: “그럼 찾아야지.” 주인공: “……찾을 수 있을까?” 계란이: “찾아보지도 않고 포기할 순 없잖아.” 삼순이: “혼자 찾을 필요 없어.” 남순이: “같이 가자! 우리가 도와줄게!”

이 장면을 통해 묵찌빠 시스템이 단순한 스킬 UI가 아니라 여행을 함께하는 세 친구의 도움이라는 의미를 갖게 한다. 세 마리는 항상 주인공 옆을 따라다니며 화면을 복잡하게 하지 않고, 스토리 장면과 특수기 발동 순간을 중심으로 등장한다.

14-7. Stage 10 엔딩 — 가족 재회와 세 친구의 작별

Stage 10에서 마을 길고양이 대장의 도움으로 가족이 구조된 집을 찾아낸다. 창가에 엄마와 형제들이 나타나고, 주인공은 마침내 가족과 재회한다.

조금 떨어진 곳에서 계란이·삼순이·남순이가 그 모습을 바라본다. 남순이가 주인공에게 다가가려 하지만 계란이가 멈추고, 삼순이는 가족을 찾은 주인공을 보며 미소 짓는다.

남순이: “우리도 가자!” 계란이: “아니. 이제 됐어.” 삼순이: “찾았잖아. 자기 가족.” 주인공: “고마워.” 계란이: “가족 잘 지켜.” 삼순이: “이제 혼자 있지 마.” 남순이: “형! 다음에 또 만나!”

세 마리는 골목길을 따라 떠난다. 남순이는 몇 번 뒤돌아보고, 삼순이가 그 뒤를 따른다. 마지막으로 계란이가 멈춰 주인공을 한 번 바라본 뒤 돌아선다. 주인공은 친구들이 사라질 때까지 바라보다 다시 엄마와 형제들이 기다리는 집으로 돌아간다.

“집은 장소가 아니었다. 함께 있는 곳이, 집이었다.”
“그리고 어떤 길은, 함께 걸어준 친구 덕분에 끝까지 갈 수 있었다.”

Alpha 0.1.2에서 적의 움직임이 루즈하고 상태 변화가 약하게 느껴졌다. Alpha 0.2.0에서는 단순 속도 증가가 아니라 상태 기반 움직임과 애니메이션을 적용한다.

SPAWN → ENTER → APPROACH → NOTICE → WARNING → ATTACK_PREPARE → ATTACK → HIT/PLAYER RESPONSE → RECOVER → REPOSITION → NEXT ATTACK / RETREAT
  • ENTER: 화면 밖에서 자연스럽게 등장.
  • APPROACH: 가속/감속이 있는 이동.
  • NOTICE: 주인공 발견 시 머리/귀/몸 방향 변화.
  • WARNING: 명확한 공격 예고.
  • ATTACK_PREPARE: 공격 종류별 고유 준비 자세.
  • ATTACK: 짧은 순간 가속과 공격 동작.
  • HIT: Hit Flash + Hit Stop + Knockback.
  • RECOVER: 공격 후 몸을 추스르는 후속 동작.
  • REPOSITION: 같은 자리 반복 공격을 피하고 위치를 변경.

15-1. 주인공 공격을 묵·찌·빠 3종으로 재설계

Alpha 0.2.0의 주인공 공격은 단일 공격 버튼 중심이 아니라 묵·찌·빠 3종 공격 스킬로 구분하는 방향을 현재 기준으로 사용한다. 각 공격은 단순 데미지 차이가 아니라 움직임과 용도가 확실히 달라야 한다.

공격동작전투 성격
👊 묵지상에서 힘을 실은 강한 앞발 후려치기강한 단발 데미지 / 넉백
✌️ 찌높이 도약한 뒤 앞발로 내려치기공중 적 대응 / 수직 공격 / 착지 타격
🖐️ 빠몸을 낮추고 전방으로 빠르게 돌진거리 좁히기 / 전진 공격 / 연계

일반 이동 점프는 조이스틱 위 입력으로 유지하며, 찌 공격의 도약은 공격용 특수 도약으로 구분한다.

15-2. 캐릭터 표시 크기 1.8배 확대

현재 플레이 영상에서 배경에 비해 캐릭터가 작아 액션이 잘 읽히지 않는 문제가 있으므로, 게임 플레이에 표시되는 캐릭터 크기를 현재 대비 1.8배로 확대한다.

  • 주인공: 현재 표시 크기의 1.8배.
  • 일반 적: 현재 표시 크기의 1.8배를 기본 기준으로 하되 적 종류별 체급 차이는 유지.
  • 계란이·삼순이·남순이: 특수기 발동 시 현재 대비 1.8배 기준으로 가독성을 확보.
  • Boss: 주인공보다 명확히 큰 체급 관계를 유지한다.
  • Sprite만 확대하지 말고 Collider/HitBox/HurtBox/Attack Range/Ground Offset/Camera Framing을 함께 재조정한다.
  • 확대 후 화면을 과도하게 가리지 않는지 실기기 Portrait 환경에서 반드시 확인한다.

15-3. 특수스킬 UI 위치 변경

계란이·삼순이·남순이 특수스킬 버튼/게이지는 하단 중앙의 큰 카드 형태에서 벗어나 왼쪽 하단 조이스틱 바로 위로 이동한다.

[계란이 특수기] [삼순이 특수기] [남순이 특수기] ↓ [가상 조이스틱]

오른쪽 조작 영역은 주인공의 묵·찌·빠 공격에 집중하고, 왼쪽은 이동 + 친구 특수기로 역할을 분리한다. 특수스킬 UI는 전투 화면을 가리지 않도록 작고 명확하게 구성하되 MAX 상태는 Glow/Pulse로 즉시 알아볼 수 있어야 한다.

15-4. 남순이 특수기 캐릭터 미표시 버그 — 최우선 수정

현재 남순이 특수기 발동 시 효과/로직은 실행되지만 남순이 캐릭터가 화면에 보이지 않는 버그가 있다. Alpha 0.2.0 다음 수정에서 우선적으로 해결한다.

Gauge MAX → Summon Trigger → Namsuni Spawn → Sprite/Animator 존재 확인 → visible=true / alpha=1 → 올바른 Render Layer / Z-Order → 주인공 왼쪽 뒤 화면 안쪽에서 등장 → 주인공 추월 → 앞에서 잠시 정지 → ✨ 반짝!! → 고속 직선 돌진 → 몸통박치기 → Impact + Hit Stop + Damage + Strong Knockback → Recoil / Recover → 오른쪽 퇴장 → Despawn

다음 항목을 반드시 검사한다: 잘못된 Spawn 좌표, Camera 밖 생성, SpriteRenderer/Image 비활성, alpha=0, 잘못된 z-order, Animator state에서 hidden 처리, Sprite reference 누락, 너무 빠른 despawn, Coroutine 취소, parent clipping/mask 문제.

테스트 완료 조건: 남순이가 발동 순간부터 퇴장할 때까지 실제 캐릭터 스프라이트로 명확하게 보이고, 공격 판정과 애니메이션이 같은 위치에서 일치해야 한다.

현재 일부 배경 BGM에서 치지직/지지직거리는 불쾌한 잡음이 들리는 문제가 있으므로, Alpha 0.2.0에서는 모든 BGM을 깨끗하고 선명한 16-bit 레트로 게임풍 사운드로 제작/재생한다.

  • 금지: 치지직, 지지직, 화이트 노이즈, 라디오 잡음, 테이프 히스, 전기 노이즈, 디지털 깨짐, 과도한 디스토션, 클리핑.
  • 폐허/재개발/비/하수도 분위기를 표현하더라도 BGM 자체를 노이즈로 더럽히지 않는다.
  • 16-bit 감성은 Square/Pulse, Triangle, 깨끗한 FM Synth, 짧고 선명한 PCM Drum, Retro Bass 등으로 표현한다.
  • 공사장/바람/비/금속음/물방울 같은 환경음은 BGM과 별도 Ambient 채널로 분리한다.

  • Stage 1은 쓸쓸한 16-bit 멜로디 + 따뜻한 Synth/Piano를 기본으로 하고, 전투 시 깨끗한 Retro Drum/Bass Layer를 추가한다.
